## Projets

### [Chatbot RAG local avec function calling et évaluation RAGAS](https://github.com/Riadh-Ouazib/chatbot-rag-traiteur) (2026)

*Python, LangChain, ChromaDB, Ollama, Streamlit, RAGAS*

- Assistant de questions-réponses sourcées, 100 % local (qwen3 4B via Ollama) : le code, et non le LLM, retrouve les sources et recopie les allergènes pour éviter les hallucinations.
- Calcul des frais de livraison par function calling (zones, majorations, TVA).
- Jeu de 30 questions de test et comparaison de deux stratégies de découpage : hit rate@6 de 82 % à 91 %, règles métier de 73 % à 93 %. Juge RAGAS externe (Nemotron 120B) pour éviter le biais d'auto-évaluation.
